Privacy Policy

Bad Guys Movie Club Bot · Last updated: September 16, 2026

This policy explains what data Bad Guys Movie Club Bot (“the Bot,” “we,” “us”) collects when you use it in a Discord server, why we collect it, and what your options are. If you invite the Bot to a server or interact with it, this policy applies to you.

Data We Collect

The Bot collects the following information when you use its commands or participate in a vote:

  • Discord User ID. A unique number Discord assigns to your account. We use this to identify who cast which vote and to prevent duplicate submissions.
  • Server (Guild) ID and Channel ID. These identify where a vote or command took place, so results get posted back to the right place.
  • Slash command inputs. When you use a command to submit a ranking or vote, we store the values you provide so we can tally results.
  • Discord username or display name. Used only to label results (for example, showing who voted) if your server’s poll settings display voter names.

The Bot does not have access to, and does not collect, the content of regular messages sent in your server. We do not collect your email address, IP address, or any information outside of what Discord’s API provides through slash command interactions.

How We Use This Data

We use the data above to:

  • Run ranked-choice tallies and post results
  • Prevent duplicate or invalid votes
  • Troubleshoot bugs when something goes wrong with a poll
  • Improve how the Bot works over time

We don’t use your data for advertising, and we don’t build profiles of users beyond what’s needed to run a given vote.

Data Storage and Security

Vote data is stored in a database connected to the Bot’s hosting environment. We take reasonable steps to secure this data, but no system is perfectly secure, and we can’t guarantee absolute protection against unauthorized access.

Data Retention

We keep vote records until the server owner requests deletion. Server owners can also request deletion (see below).

Data Sharing

We don’t sell, rent, or share your data with third parties. The only exception is if we’re required to disclose it by law, or if it’s necessary to investigate abuse of the Bot (such as vote manipulation).

Your Rights

You can request that we delete your data by contacting us at alex@overshare.tv. Server owners can also request deletion of all vote data tied to their server by removing the Bot, which triggers deletion of associated records within 30 days.

If you have questions about what data we hold about you, reach out at the same address and we’ll do our best to answer.

Children’s Privacy

The Bot is not intended for use by anyone under 13, consistent with Discord’s own age requirements. We don’t knowingly collect data from users under 13.

Changes to This Policy

We may update this policy as the Bot’s features change. If we make material changes, we’ll note the new “Last updated” date above. Continued use of the Bot after changes means you accept the updated policy.

Contact

Questions about this policy or how your data is handled: alex@overshare.tv
